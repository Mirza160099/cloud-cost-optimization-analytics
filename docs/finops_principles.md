# FinOps Principles Demonstrated

## Visibility
Understand where spend occurs by:
- provider
- service
- environment
- owner
- region

## Optimisation
Prioritise:
- idle compute
- oversized compute
- underused storage
- network-service outliers
- commitment discount coverage

## Accountability
Use tags and ownership to connect cost to responsible teams.

## Continuous Improvement
Cloud cost optimisation is not a one-off exercise. Production environments should continuously review:
- utilisation
- anomaly alerts
- forecasts
- commitments
- architectural changes
- business demand
